# Test strategy

Rule zero: expected values come from an independent source, never from the code under test. Each test that asserts a number says where the number came from (hand calculation in a comment, `fractions.Fraction`, a published worked example).

## Layers

| Layer | Tool | Scope | Runs |
|:------|:-----|:------|:-----|
| Unit | pytest | every engine function, every issue code path | every commit |
| Property | hypothesis | the relationships in `04-financial-engine-spec.md` section 5, plus ownership and tax monotonicity | every commit |
| Golden dataset | pytest + files in `tests/golden/` | fictional `DEMO DATA` companies and people with full expected outputs | every commit; diffs need an explanation in the PR |
| Integration | pytest + real PostgreSQL (service container in CI, local cluster in dev) | migrations, constraints, RLS, services, repositories | every commit |
| API contract | pytest + httpx | every endpoint: success, validation error, auth error, tenant isolation; OpenAPI schema snapshot | every commit |
| Frontend unit | Vitest | formatting, components, data mapping | every commit |
| E2E | Playwright (Chromium in `/opt/pw-browsers`) | sign in, create company, enter financials, value, wealth map, report PDF | every PR |
| Security | pytest + scanners | authz matrix (role x endpoint), cross-tenant reads, CSRF, rate limits, dependency audit (`pip-audit`, `pnpm audit`), secret scan | every PR |
| Performance | pytest-benchmark + scripts | engine throughput, batch of 10,000 synthetic companies, API latency, query plans | phase 17 and 18, then weekly |
| AI | eval set | right tool, numbers in output equal numbers in input, no invented figures, disclaimer present, JSON contract valid | on prompt or model change |

## Mandatory financial tests

WACC, CAPM, DCF, FCFF, terminal value, enterprise value, equity value, each multiple, asset-based, weighted range, sensitivity grids, scenarios, tax rules (each status, each version, supersession), ownership look-through.

## Edge cases (each one a named test)

Zero revenue, negative EBITDA, negative FCF, negative equity, zero debt, high debt (net debt above EV), missing data, one financial year, three years, five years, `WACC <= g`, invalid ownership, circular ownership, duplicate company, duplicate period, invalid currency, stale data, float input, NaN and infinity input.

## Golden dataset

- At least five fictional companies covering: stable profitable, high growth, loss making, asset heavy holding, distressed with high debt.
- At least three fictional people: below the wealth-tax threshold, near it, far above it with a holding chain and foreign assets.
- Every record has `is_demo = true` and names that are obviously fictional ("Demo Alfa Kft.", "Demo Person A").
- Expected outputs are computed independently (spreadsheet or hand calculation) and committed with the method.
- Run before every release; a changed golden output blocks release until explained.

## Synthetic benchmark data

Generated by a seeded script, labelled `SYNTHETIC`, never written to production, never shown as market statistics.

## CI gates

A PR merges only when lint, typecheck, unit, property, golden, integration, API contract, frontend build, security checks, and E2E all pass. No test is skipped or loosened to get green.

## Definition of done for a phase

1. Tests for the phase written and passing.
2. Full regression suite passing.
3. Architecture rules in `CLAUDE.md` checked.
4. Self-review as CTO, CFO, modeller, tax specialist, security engineer, QA, product; findings fixed or recorded.
5. Docs updated, including `06-roadmap.md` status.
